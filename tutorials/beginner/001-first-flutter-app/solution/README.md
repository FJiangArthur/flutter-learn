# Tutorial 001 Solution: Your First Flutter App

This is the complete solution for Tutorial 001.

## How to Run

```bash
cd solution
flutter pub get
flutter run
```

## What This App Does

- Displays "Hello, Flutter!" in the center of the screen
- Has a Material Design app bar with the title "My First App"
- Uses a Scaffold for basic layout structure

## Key Concepts Demonstrated

1. **main() function** - Entry point of the app
2. **runApp()** - Starts the Flutter engine
3. **StatelessWidget** - Widget that doesn't change
4. **MaterialApp** - Provides Material Design
5. **Scaffold** - Basic screen structure
6. **AppBar** - Top navigation bar
7. **Center** - Centers child widget
8. **Text** - Displays text
