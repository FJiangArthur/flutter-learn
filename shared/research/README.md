# Research Notes

Use this directory to document your learnings from external resources.

## How to Use

For each project, create a markdown file to capture:
- Useful articles you found
- Video tutorials that helped
- Stack Overflow solutions
- Code snippets you discovered
- "Aha!" moments
- Things you struggled with and how you solved them

## Template

Create files like `project-01-notes.md`, `project-02-notes.md`, etc.

Use this structure:

```markdown
# Project X: [Project Name] - Research Notes

## Date: YYYY-MM-DD

---

## Resources Found

### Article: [Title]
- **URL:** https://...
- **Key Takeaways:**
  - Point 1
  - Point 2
- **Code Examples:**
  ```dart
  // Useful code from article
  ```

### Video: [Title]
- **URL:** https://...
- **Key Concepts:**
  - Concept 1
  - Concept 2
- **Timestamp Notes:**
  - 5:30 - Explains setState()
  - 12:45 - Shows navigation pattern

### Stack Overflow: [Question Title]
- **URL:** https://stackoverflow.com/...
- **Problem:** What you were trying to solve
- **Solution:** What worked
- **Code:**
  ```dart
  // Solution code
  ```

---

## Challenges & Solutions

### Challenge 1: [Description]
**Problem:**

- What you learned from this

## Tips

- **Document as you go** - Don't wait until the end
- **Include URLs** - You'll want to revisit resources
- **Copy code snippets** - Create your own knowledge base
- **Note what didn't work** - Learn from mistakes
- **Tag concepts** - Use hashtags like #navigation #state #async
- **Add timestamps** - Track your learning progress
